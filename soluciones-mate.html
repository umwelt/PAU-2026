Resolución guiada con planteamiento, sustitución y resultado. Se incluyen las dos opciones 4A/4B y 5A/5B aunque en el examen real solo se elija una.

Examen 1 · Vitalcor

Fármaco · matriz 2×2 · distancia · L'Hôpital · test médico
10 pts
1. Vitalcor 2 pts · obligatorio
a) Continuidad en x=3:
lim x→3⁻ f(x) = −3² + 6·3 = −9 + 18 = 9 lim x→3⁺ f(x) = 18/(3 − 1) = 9 f(3) = 18/2 = 9. Los tres valores coinciden → f continua en x = 3
b) Monotonía:
En (0,3): f'(x) = −2x + 6 > 0 ⟺ x < 3 → estrictamente creciente En (3,∞): f(x) = 18/(x−1) → f'(x) = −18/(x−1)² < 0 → decreciente Máximo en x = 3 → f(3) = 9 mg/L
c) lim x→∞ 18/(x − 1) = 0 mg/L. La concentración tiende a cero (el organismo elimina por completo el fármaco).
2. Matriz M(a) 2 pts · obligatorio
a) det(M) = 1·(3−a) − (a−2)·(−1) = (3−a) + (a−2) = 1 ≠ 0 para todo a.
M⁻¹ = (1/det)·adj(M) = adj(M) = ((3−a, 2−a); (1, 1))
b) Para a=2: M = ((1,0);(−1,1)), M⁻¹ = ((1,0);(1,1)). Despejamos: X = M⁻¹(B − MA).
MA = ((0, 1, 2); (1, −2, −2)) B − MA = ((1, 1, 2); (−2, 2, 5)) X = M⁻¹·(B−MA) → X = ((1, 1, 2); (−1, 3, 7))
3. Geometría · distancia y ángulo 2 pts · obligatorio
a) Punto Q = r₁ ∩ r₂:
De r₂: x = 1, y + z = 3. De r₁: x − z = −1 → 1 − z = −1 → z = 2, y = 1. Q = (1, 1, 2) d(P,Q) = √((2−1)² + (−1−1)² + (3−2)²) = √(1+4+1) → d = √6 ≈ 2,449
b) Direcciones: v₁ = (1, 0, 1) (de r₁), v₂ = (0, 1, −1) (de r₂).
cos α = |v₁·v₂|/(|v₁|·|v₂|) = |0 + 0 − 1|/(√2·√2) = 1/2 α = arccos(1/2) = 60°
4A · Límite + función a trozos derivable 2 pts
a) lim x→0 (1/x − 1/tan x) = lim (tan x − x)/(x·tan x). Indeterminación 0/0.
Taylor: tan x ≈ x + x³/3 → tan x − x ≈ x³/3; x·tan x ≈ x² Cociente ≈ (x³/3)/x² = x/3 → 0
b) Continuidad: f(0⁻) = e⁰·sen(0) = 0; f(0⁺) = b/1 = b. Entonces b = 0.
f'(x<0) = a·e^(ax)·sen(bx) + b·e^(ax)·cos(bx). En x=0: 0 + b·1·1 = 0 (porque b=0) f'(x≥0): derivada del cociente (x²+ax)/(x+1) en 0 → ((0+a)·1 − 0)/1 = a Derivable: f'(0⁻)=f'(0⁺) ⟹ 0 = a → a = 0, b = 0
4B · Integral por partes + área 2 pts
a) ∫ x²·ln(x) dx por partes: u = ln(x), dv = x² dx → du = dx/x, v = x³/3.
∫ x²·ln(x) dx = (x³/3)·ln(x) − ∫ (x³/3)·(1/x) dx = (x³/3)·ln(x) − x³/9 + C ∫ x²·ln(x) dx = (x³/9)·(3·ln(x) − 1) + C
b) Cortes f=g: x² − 2x = x → x² − 3x = 0 → x(x−3) = 0 → x = 0 y x = 3.
En (0,3): g − f = x − (x²−2x) = 3x − x² > 0 Área = ∫₀³ (3x − x²) dx = [3x²/2 − x³/3]₀³ = 27/2 − 9 → 9/2 u²
5A · Test médico Bayes 2 pts
a) Probabilidad total:
P(T+) = P(E)·P(T+|E) + P(¬E)·P(T+|¬E) = 0,02·0,96 + 0,98·0,05 = 0,0192 + 0,049 → P(T+) = 0,0682
b) Bayes: P(E|T+) = P(T+|E)·P(E)/P(T+) = 0,0192/0,0682 → ≈ 0,2815 (28,2%).

Resultado clásico: con prevalencia baja, incluso un test "muy bueno" da muchos falsos positivos.

5B · Normal Anaga 2 pts
a) X ~ N(1200, 200). Z = (X−1200)/200.
P(1000 ≤ X ≤ 1500) = P(−1 ≤ Z ≤ 1,5) = F(1,5) − F(−1) = F(1,5) − (1 − F(1)) = 0,9332 − 0,1587 → 0,7745 (77,45%)
b) P(X > 1600) = P(Z > 2) = 1 − F(2) = 1 − 0,9772 = 0,0228 (2,28%).
En 30 días: 30·0,0228 ≈ 0,68 días → ≈ 1 día con desbordamiento
Notación. En el apartado 1a se pide "justificar", no basta con sustituir; hay que escribir los tres valores y concluir. En 5A muchos alumnos olvidan que P(T+|¬E) = 1 − especificidad = 0,05 (no 0,95).

Examen 2 · Lubinas

Logística · Rouché-Fröbenius · simétrico · Bayes urnas
10 pts
1. Lubinas 2 pts · obligatorio
a) N(0) = 2000/(1 + 9·1) = 2000/10 = 200 lubinas (en cientos).
N'(t) = 2000·(0 − 9·(−0,4)e^(−0,4t))/(1 + 9e^(−0,4t))² = (2000·3,6·e^(−0,4t))/(1+9e^(−0,4t))² El numerador es siempre > 0 y el denominador positivo → N'(t) > 0 ∀t → N creciente siempre
b) Capacidad de carga: lim t→∞ 2000/(1 + 9·0) = 2000.
N(t) = 1000 ⟺ 1 + 9e^(−0,4t) = 2 ⟺ e^(−0,4t) = 1/9 ⟺ −0,4t = −ln(9) ⟺ t = ln(9)/0,4 t ≈ 5,49 meses
c) N(5) = 2000/(1 + 9·e^(−2)) = 2000/(1 + 1,218) ≈ 902. TVM[0,5] = (902 − 200)/5 = 140,4 lubinas/mes.
2. Sistema con parámetro k 2 pts · obligatorio
a) Matriz de coeficientes A, ampliada A*:
|A| = det de ((1,1,1);(2,k,1);(1,1,k+1)) = 1·(k(k+1) − 1) − 1·(2(k+1) − 1) + 1·(2 − k) = k² + k − 1 − 2k − 1 + 2 − k = k² − 2k = k(k − 2) Casos: - Si k ≠ 0 y k ≠ 2: rg(A) = rg(A*) = 3 → SCD - Si k = 0: estudiar rangos, sale rg(A)=2, rg(A*)=2 → SCI - Si k = 2: rg(A)=2, rg(A*)=3 → SI (incompatible)
b) Para k = 1: {x+y+z=1; 2x+y+z=2; x+y+2z=1}.
E₂ − E₁: x = 1. Sustituyendo en E₁: y + z = 0. En E₃: y + 2z = 0 → z = 0, y = 0. x = 1, y = 0, z = 0
3. Simétrico respecto a un plano 2 pts · obligatorio
a) Vector normal a π: n⃗ = (2, 1, −1). Recta perpendicular a π por P(1,2,0):
s: (x, y, z) = (1+2t, 2+t, −t)
b) Intersección s ∩ π:
2(1+2t) + (2+t) − (−t) = 4 → 2 + 4t + 2 + t + t = 4 → 6t + 4 = 4 → t = 0 ¡Pero t = 0 da P! Esto significa que P ∈ π. Verificación: 2·1 + 2 − 0 = 4 ✓ (P está en π). P pertenece a π, por tanto P′ = P = (1, 2, 0)

Para evitar este caso degenerado en el examen real, comprobar siempre antes si P pertenece o no al plano.

4A · L'Hôpital + derivable 2 pts
a) lim x→0 (sen(2x) − 2x)/x³ es 0/0. Aplicar L'Hôpital tres veces:
L1: (2cos(2x) − 2)/(3x²) en 0: (2−2)/0 = 0/0 L2: (−4sen(2x))/(6x) en 0: 0/0 L3: (−8cos(2x))/6 en 0 = −8/6 → −4/3
b) Continuidad en x=1: a·1 + b = ln(1) + 1 = 1 → a + b = 1.
Derivable: a = 1/1 + 2·1 = 3 (derivada de ln(x)+x² en x=1) Sustituyendo: 3 + b = 1 → a = 3, b = −2
4B · Integral + área 2 pts
a) ∫ x·cos(2x) dx, por partes: u = x, dv = cos(2x) dx → du = dx, v = sen(2x)/2.
= (x·sen(2x))/2 − ∫ sen(2x)/2 dx = (x·sen(2x))/2 + cos(2x)/4 + C ∫ x·cos(2x) dx = (2x·sen(2x) + cos(2x))/4 + C
b) Área entre y = 4 − x² y eje OX. Cortes: 4 − x² = 0 → x = ±2.
Área = ∫₋₂² (4 − x²) dx = 2·∫₀² (4 − x²) dx = 2·[4x − x³/3]₀² = 2·(8 − 8/3) = 2·(16/3) → Área = 32/3 ≈ 10,67 u²
5A · Bayes con tres urnas 2 pts
a) P(B) = P(U₁)·(3/5) + P(U₂)·(4/8) + P(U₃)·(2/5) = (1/3)·(3/5 + 1/2 + 2/5)
= (1/3)·(6/10 + 5/10 + 4/10) = (1/3)·(15/10) → P(B) = 1/2
b) P(U₂|B) = P(B|U₂)·P(U₂)/P(B) = (1/2)·(1/3)/(1/2) = 1/3 (33,3%).
5B · Binomial → Normal 2 pts
a) X ~ B(80, 0,3). np = 24, nq = 56. Ambos ≥ 5 → aproximamos por N(24, σ) con σ = √(80·0,3·0,7) = √16,8 ≈ 4,10.
P(20 ≤ X ≤ 30) ≈ P(19,5 ≤ Y ≤ 30,5) con corrección de continuidad Z₁ = (19,5−24)/4,10 ≈ −1,10 → F(−1,10) = 1 − 0,8643 = 0,1357 Z₂ = (30,5−24)/4,10 ≈ 1,59 → F(1,59) ≈ 0,9441 P ≈ 0,9441 − 0,1357 → ≈ 0,8084 (80,84%)
b) P(X > 35) ≈ P(Y > 35,5). Z = (35,5−24)/4,10 ≈ 2,80. F(2,80) = 0,9974.
P(X > 35) ≈ 1 − 0,9974 → ≈ 0,0026 (0,26%)
Atajo. En 1b: cuando se busca el instante en que una logística alcanza la mitad de su capacidad, basta resolver el denominador = 2 (los dos factores iguales) — no hace falta derivar.

a) C(0) = 8(1−e⁰) = 0 mg/L. C'(t) = 8·0,4·e^(−0,4t) = 3,2·e^(−0,4t) > 0 ∀t → C creciente siempre.
b) lim t→∞ C(t) = 8·(1−0) = 8 (asíntota horizontal y=8). C nunca supera 8.

c) C ≥ 6 ⟺ 1−e^(−0,4t) ≥ 0,75 ⟺ e^(−0,4t) ≤ 0,25 ⟺ t ≥ ln(4)/0,4 → t ≥ 3,47 h

a) Con A(k) = (1,1,1; 1,k,1; 2,1,k):
|A(k)| = 1·(k²−1) − 1·(k−2) + 1·(1−2k) = k²−3k+2 = (k−1)(k−2) Si k ≠ 1 y k ≠ 2: rg(A) = 3 Si k = 1: A = (1,1,1; 1,1,1; 2,1,1). Submatriz (1,1;2,1) det = −1 ≠ 0 → rg = 2 Si k = 2: A = (1,1,1; 1,2,1; 2,1,2). Submatriz (1,1;1,2) det = 1 ≠ 0 → rg = 2
b) Para k=3: A·x = (4,4,5).
x+y+z=4; x+3y+z=4; 2x+y+3z=5 E₂−E₁: 2y = 0 → y = 0 E₁: x+z = 4. E₃: 2x+3z = 5. De la primera x = 4−z. Sustituyendo: 8−2z+3z = 5 → z = −3 x = 7 → (x, y, z) = (7, 0, −3)
3. Plano que contiene r₁ paralelo a r₂ 2 pts · obligatorio
a) v₁ = (2, 1, −1); v₂ = (1, −1, 2). v₁×v₂ = (1·2−(−1)·(−1), −((2·2−(−1)·1)), 2·(−1)−1·1) = (1, −5, −3).
P₁(1,−1,2) ∈ r₁; P₂(1,2,3) ∈ r₂; P₁P₂ = (0, 3, 1) det(v₁, v₂, P₁P₂) = ... ≠ 0 → r₁ y r₂ se cruzan
b) Plano π contiene a r₁ y paralelo a v₂. Vector normal: v₁×v₂ = (1, −5, −3). Pasa por P₁(1,−1,2):
1·(x−1) − 5·(y+1) − 3·(z−2) = 0 → x − 5y − 3z + (−1 − 5 + 6) = 0 π: x − 5y − 3z = 0
4A · A trozos exp/log 2 pts
a) Continuidad en x=0: f(0⁻) = e⁰ = 1; f(0⁺) = ln(1) + 0 + 1 = 1. Continua para todo a, b.
b) Derivable: f'(x<0) = a·e^(ax) → f'(0⁻) = a. f'(x≥0) = 1/(x+1) + b → f'(0⁺) = 1 + b.
a = 1 + b. La continuidad y derivabilidad solo da una ecuación. Falta otra condición: El enunciado pide hallar a, b específicos. Asumiendo que se requiere continuidad de la 2ª derivada o un valor adicional. Con la condición dada: Toda pareja (a, b) con a = b + 1 hace f derivable en x = 0

Nota: con la información del enunciado solo se obtiene una relación. En la PAU real suelen añadir una condición extra (p.ej. f(1)=valor) que aquí se omite por brevedad.

4B · Optimización · caja 2 pts
a) V = x²·h = 32 → h = 32/x². Área (sin tapa): A = x² + 4·x·h = x² + 128/x.
b) A'(x) = 2x − 128/x². A'(x) = 0 ⟺ 2x = 128/x² ⟺ x³ = 64 ⟺ x = 4 dm.
A''(x) = 2 + 256/x³ > 0 → mínimo h = 32/16 = 2 dm. A_mín = 16 + 32 = x = 4 dm, h = 2 dm, A = 48 dm²

b) P(1 roja y 1 verde, cualquier orden) = (4/10)·(3/9) + (3/10)·(4/9) = 12/90 + 12/90 = 24/90 = 4/15 ≈ 0,267

Examen 4 · Festival turístico

Recaudación · sistema matricial · ángulo rectas · Lanzarote
10 pts
1. Festival turístico 2 pts · obligatorio
a) B(p) = p(5000 − 50p) − 80 000 = −50p² + 5000p − 80 000. B'(p) = −100p + 5000 = 0 → p = 50 €. B(50) = −125 000 + 250 000 − 80 000 = 45 000 €
b) B(p) ≥ 0 ⟺ 50p² − 5000p + 80 000 ≤ 0. Raíces: p = (5000 ± √(25·10⁶ − 16·10⁶))/100 = (5000 ± 3000)/100 = 20 o 80.
B(p) ≥ 0 para 20 € ≤ p ≤ 80 €
c) Con costes 100 000: máximo B = −50·50² + 5000·50 − 100 000 = 25 000 € > 0. Sí, sigue siendo posible obtener beneficio.
2. Sistema matricial 2 pts · obligatorio
a) Sumando 2X+Y = A y 2·(X−Y) = 2B: 2X+Y+2X−2Y = A+2B → 4X − Y = A+2B. Por sumar a primera: 3X = A + (A+2B)/... Mejor:
Sumar las dos: (2X+Y) + 2·(X−Y) = A + 2B → 4X − Y = A+2B. No simplifica. Eliminar Y: 1·E₁ + 1·E₂ → 3X + 0 = A+B → X = (A+B)/3 A+B = ((1+4, 2−1);(3+2, 4+5)) = ((5,1);(5,9)) X = ((5/3, 1/3);(5/3, 3)) Y = A − 2X = ((1,2);(3,4)) − ((10/3, 2/3);(10/3, 6)) = ((−7/3, 4/3);(−1/3, −2))
b) |X| = (5/3)·3 − (1/3)·(5/3) = 5 − 5/9 = 40/9 ≠ 0 → X invertible.
|Y| = (−7/3)·(−2) − (4/3)·(−1/3) = 14/3 + 4/9 = 42/9 + 4/9 = 46/9 ≠ 0 → Y invertible
3. Ángulo entre rectas 2 pts · obligatorio
a) r₂ paramétricas: del sistema {x+y−z=0; x−y+z=2}, sumando: 2x = 2 → x = 1. Restando: 2y − 2z = −2 → y = z − 1. Parametrizando z = t: r₂: (1, t−1, t), v₂ = (0, 1, 1)
b) v₁ = (3, 1, 2), v₂ = (0, 1, 1). Comprobar punto común: r₁ pasa por (1,2,0), r₂ por (1,−1,0). Vector P₁P₂ = (0, −3, 0). det(v₁,v₂,P₁P₂)=...
det = 3·(1·0 − 1·(−3)) − 1·(0 − 0) + 2·(0 − 0) = 3·3 = 9 ≠ 0 → no son coplanares → se cruzan, no se cortan Si el problema exige el ángulo (aunque no se corten): cos α = |v₁·v₂|/(|v₁|·|v₂|) = |0+1+2|/(√14·√2) = 3/√28 α = arccos(3/√28) ≈ 55,5°
4A · Asíntotas 2 pts
a) Dominio: ℝ \ {1} (denominador). Vertical en x=1: lim x→1⁻ = −∞ (numerador 4>0, denominador 0⁻), lim x→1⁺ = +∞.
Asíntota vertical: x = 1
b) División polinómica: (x²+3)/(x−1) = x + 1 + 4/(x−1).
Asíntota oblicua: y = x + 1
c) Para x→+∞, f(x) ≈ x+1, ligeramente por encima (4/(x−1) > 0). Para x→−∞, ligeramente por debajo. Cerca de x=1, salta de −∞ a +∞.
4B · Integral por sustitución 2 pts
a) u = 2x−1, du = 2dx, x = (u+1)/2.
∫ x·√(2x−1) dx = ∫ (u+1)/2·√u·(du/2) = (1/4)∫ (u^(3/2) + u^(1/2)) du = (1/4)·(2u^(5/2)/5 + 2u^(3/2)/3) + C = u^(5/2)/10 + u^(3/2)/6 + C ∫ x·√(2x−1) dx = (2x−1)^(5/2)/10 + (2x−1)^(3/2)/6 + C

= (1/2)∫₀⁹ √u du = (1/2)·(2u^(3/2)/3)|₀⁹ = (1/3)·27 → 9 u²

Examen 5 · Cerámica

Trozos · A²=2A−I · perpendicular común · L'Hôpital · ULPGC
10 pts
1. Cerámica 2 pts · obligatorio
a) lim t→2⁻ T(t) = 800−50·4 = 600. lim t→2⁺ T(t) = 600·e⁰ = 600. T(2) = 600. Continua en t=2 ✓.
b) Tramo (0,2): T'(t) = −100t → T'(1) = −100 °C/min.
Tramo (2,∞): T'(t) = 600·(−0,1)·e^(−0,1(t−2)) = −60·e^(−0,1(t−2)) T'(4) = −60·e^(−0,2) ≈ −60·0,819 ≈ −49,1 °C/min Interpretación: la pieza se enfría más rápido al principio (régimen polinómico) que después (régimen exponencial amortiguado).
c) lim t→∞ 600·e^(−0,1(t−2)) = 0 °C. Interpretación: T(t) tiende al cero absoluto en este modelo (irreal — el modelo solo es válido para tiempos moderados; en realidad tendería a la temperatura ambiente).
2. A² = 2A − I y A^n 2 pts · obligatorio
a) A = (2,1;−1,0). A² = (2·2+1·(−1), 2·1+1·0; −1·2+0·(−1), −1·1+0·0) = (3, 2; −2, −1).
2A − I = (4,2;−2,0) − (1,0;0,1) = (3, 2; −2, −1) → A² = 2A − I ✓
b) Inducción: suponemos A^n = nA − (n−1)I. Entonces A^(n+1) = A·A^n = A·(nA − (n−1)I) = nA² − (n−1)A = n(2A−I) − (n−1)A = (2n − n + 1)A − nI = (n+1)A − nI. ✓
A⁵ = 5A − 4I = (10,5;−5,0) − (4,0;0,4) → A⁵ = (6, 5; −5, −4)
3. Perpendicular común 2 pts · obligatorio
a) v₁ = (1, 2, −1); v₂ = (1, −1, 1). v₁ no paralelo a v₂. Punto P₁(2,0,1), P₂(0,2,1). P₁P₂ = (−2, 2, 0).
